## 1. การติดตั้งและการตั้งค่าเริ่มต้น (Installation & Setup)

เมื่อเปิดโปรแกรมครั้งแรก คุณจำเป็นต้องตั้งค่าเส้นทางไฟล์ที่สำคัญเพื่อให้โปรแกรมทำงานได้ถูกต้อง:

1. ไปที่เมนู **App Settings** (รูปประแจ)
2. **SteamCMD Path**: ระบุโฟลเดอร์ที่ติดตั้ง SteamCMD (หากยังไม่มี สามารถกดปุ่ม Install เพื่อดาวน์โหลดได้)
3. **SCUM Server Path**: ระบุโฟลเดอร์ที่ติดตั้งตัวเกม SCUM Server (เช่น `C:\SCUMServer`)
4. กดปุ่ม **Save Settings** เพื่อบันทึก

---

## 2. หน้าแดชบอร์ด (Dashboard)

เป็นหน้าแรกสำหรับดูภาพรวมและควบคุมสถานะเซิร์ฟเวอร์

*   **Server Status**: แสดงสถานะปัจจุบัน (Running, Stopped, Starting)
*   **Control Buttons**:
    *   **Start**: เปิดเซิร์ฟเวอร์
    *   **Stop**: ปิดเซิร์ฟเวอร์
    *   **Restart**: รีสตาร์ทเซิร์ฟเวอร์
    *   **Update Server**: อัปเดตแพทช์เกมผ่าน SteamCMD
*   **Server Stats**: แสดงข้อมูล CPU, RAM และจำนวนผู้เล่นออนไลน์แบบ Real-time

---

## 3. จัดการผู้เล่น (Player Manager)

ระบบจัดการผู้เล่นที่ครอบคลุม แบ่งออกเป็น 5 แถบเมนู:

### 3.1 Online Players (ผู้เล่นออนไลน์)
*   แสดงรายชื่อผู้เล่นที่กำลังออนไลน์อยู่
*   แสดงข้อมูล: ชื่อ, Steam ID, IP, Ping
*   **Action**: มีปุ่ม **Ban** เพื่อแบนผู้เล่นทันที (ระบบจะเตะและบันทึก Steam ID ลงไฟล์แบน)

### 3.2 Whitelist
*   จัดการรายชื่อผู้เล่นที่ได้รับอนุญาตเข้าเซิร์ฟเวอร์ (หากเปิดระบบ Whitelist)
*   สามารถเพิ่ม Steam ID ใหม่ หรือลบที่มีอยู่ออกได้
*   ไฟล์ที่เกี่ยวข้อง: `WhitelistedUsers.ini`

### 3.3 Banned Users (ผู้เล่นที่ถูกแบน)
*   รายชื่อผู้เล่นที่ถูกห้ามเข้าเซิร์ฟเวอร์
*   สามารถปลดแบนได้โดยการลบ Steam ID ออกจากรายการ
*   ไฟล์ที่เกี่ยวข้อง: `BannedUsers.ini`

### 3.4 Admin Users
*   จัดการรายชื่อแอดมินของเซิร์ฟเวอร์
*   ไฟล์ที่เกี่ยวข้อง: `AdminUsers.ini`

### 3.5 Server Settings Admin
*   ตั้งค่าแอดมินสำหรับการตั้งค่าเซิร์ฟเวอร์
*   ไฟล์ที่เกี่ยวข้อง: `ServerSettingsAdminUsers.ini`

> **วิธีใช้งาน**: กรอก Steam ID ในช่องว่างด้านบนแล้วกดปุ่ม **+** เพื่อเพิ่ม หรือกดปุ่มถังขยะเพื่อลบ

## 4. ตั้งค่าเกม (Game Config)

เมนูสำหรับปรับแต่งค่าต่างๆ ของเซิร์ฟเวอร์ (ไฟล์ `ServerSettings.ini`) โดยมีหัวข้อหลักคือ **Server Config**:

*   **Server Name**: ชื่อเซิร์ฟเวอร์
*   **Server Password**: รหัสผ่านเข้าเซิร์ฟเวอร์
*   **Max Players**: จำนวนผู้เล่นสูงสุด
*   **Welcome Message**: ข้อความต้อนรับ
*   **Message of the Day**: ประกาศประจำวัน
*   และค่าอื่นๆ

**การใช้งาน**:
*   แก้ไขค่าที่ต้องการในช่องต่างๆ
*   กดปุ่ม **Save to Server** เพื่อบันทึกค่าลงไฟล์
*   กดปุ่ม **Load from Server** เพื่อโหลดค่าปัจจุบันจากไฟล์

---

## 5. ระบบอัตโนมัติ (Automation)

ตั้งค่าตารางเวลาสำหรับการทำงานอัตโนมัติ เพื่อลดภาระของผู้ดูแล:

*   **Auto Restart**: ตั้งเวลาให้เซิร์ฟเวอร์รีสตาร์ทอัตโนมัติตามระยะเวลาที่กำหนด (นาที)
    *   *ระบบแจ้งเตือน*: จะมีการประกาศนับถอยหลังผ่าน RCON และ Discord (60, 30, 15, 10, 5, 3, 2, 1 นาที)
*   **Auto Backup**: สำรองข้อมูลเซิร์ฟเวอร์อัตโนมัติ
*   **Auto Update**: ตรวจสอบและอัปเดตเซิร์ฟเวอร์อัตโนมัติ

---

## 6. ดิสคอร์ดบอท (Discord Bot)

ระบบแจ้งเตือนเหตุการณ์ต่างๆ ภายในเกมไปยัง Discord Server ของคุณผ่าน Webhooks:

*   **Kill Feed**: แจ้งเตือนการฆ่ากัน (PvP/PvE)
*   **Chat Feed**: แสดงข้อความแชทในเกม
*   **Admin Feed**: บันทึกการใช้คำสั่งแอดมิน
*   **Login Feed**: แจ้งเตือนเมื่อมีคนเข้า-ออกเซิร์ฟเวอร์
*   **Gameplay Feed**: เหตุการณ์ทั่วไปในเกม
*   **System & Restart Alerts**: แจ้งเตือนระบบและการนับถอยหลังรีสตาร์ท

**วิธีตั้งค่า**:
1. สร้าง Webhook ใน Discord Channel ที่ต้องการ
2. นำ URL มาใส่ในช่อง Webhook URL ของแต่ละ Feed
3. กดเปิดสวิตช์ (Enable)
4. กด **Save Configuration**

## 7. คอนโซล (Live Console)

*   แสดง Log การทำงานของเซิร์ฟเวอร์แบบ Real-time
*   สามารถพิมพ์คำสั่ง RCON เพื่อสั่งงานเซิร์ฟเวอร์ได้โดยตรง

---

## 8. การแก้ไขปัญหาเบื้องต้น (Troubleshooting)

*   **เซิร์ฟเวอร์ไม่เปิด**: ตรวจสอบว่า `SCUM Server Path` ถูกต้อง และพอร์ตไม่ชนกับโปรแกรมอื่น
*   **RCON เชื่อมต่อไม่ได้**: ตรวจสอบ IP และ Port ของ RCON ใน `ServerSettings.ini` ว่าตรงกับที่โปรแกรมใช้ (Default: 127.0.0.1:28102)
*   **Discord ไม่แจ้งเตือน**: ตรวจสอบ Webhook URL ว่าถูกต้อง และบอทมีสิทธิ์ส่งข้อความในห้องนั้นๆ
